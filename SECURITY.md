# Güvenlik bildirimi

Açığı herkese açık issue yerine depo sahibine özel olarak bildirin (GitHub "Report a vulnerability" ya da depo sayfasındaki iletişim).
Fiziksel güvenlik (E-stop, watchdog) ile ilgili kusurlar öncelikli ele alınır; bkz. [SAFETY.md](SAFETY.md).
